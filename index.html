ACCIDENT LIFE CYCLE CONTROL

Chronology of a Saved Life

From impact detection to emergency dispatch — every microsecond is engineered to save a life. Here's how it works.

STEP 01 // ACCELERATION baseline
0.00s (Monitoring)
Continuous 60Hz Sensor Spark
The ESP32 haptic on-vehicle module samples acceleration and angular velocity constantly at 60Hz, building a real-time telemetry baseline for anomaly detection.
STEP 02 // G-FORCE SHOCKWAVE
+0.04s (Crash Event)
Impact Threshold Exceeded
A sudden collision triggers a deceleration coefficient exceeding 4.5G on the MPU6050 sensor. The combined X/Y/Z vector spike immediately flags a crash event.
STEP 03 // DEVICE SHIELD
+0.12s (Verification)
30-Second Haptic Override Timer
The hardware buzzer triggers on-helmet alert signals, initializing a 30-second countdown. If the rider presses the override button, the alarm is cancelled as a false positive.
STEP 04 // PROGRAMMATIC SMS
+1.40s (SOS Dispatch)
Twilio Emergency SOS Dispatch
If the override expires, the crash broker activates the Twilio SMS gateway, dispatching an emergency message with live Google Maps GPS coordinates to all registered emergency contacts.
STEP 05 // CONTROL DESK
+1.85s (Operations Center)
Fleet Admin Rescue Routing
The centralized operations center receives the crash alert, displays it on the live map, triggers desktop notifications, and enables the admin to coordinate rescue operations in real-time.
